## 从问题出发的学习过程

回看这本笔记的起点，最初摆在我们面前的，不过是几段简短的学习笔记和一个再普通不过的需求：“怎样从资料里找出能回答问题的段落，并估算读完它要花多少分钟？”

正是这样一个看似不起眼的实际困难，一步步推着我们走完了十一篇的漫长旅程：

1. 在**第一篇**里，我们最先试了原封不动的子串匹配，发现它连换个词提问都应付不了；改成数关键词出现次数后，又撞上了“把同一个词重复抄写十遍就能霸榜”的漏洞。为了消除篇幅长短的干扰、只比较内容的方向，我们不得不请出向量、二范数归一化与余弦相似度（`0.948683`）；而为了看懂矩阵变换究竟保留了什么、弄丢了什么，以及怎样顺着误差的方向自动调整参数，投影、特征分解、行列式、导数链式法则与交叉熵便顺理成章地进入了视野。
2. 到了**第二篇**，我们不再满足于手动试凑公式系数，而是用四条阅读时长记录走通了从线性回归梯度下降、正规方程消元反解，到逻辑回归 Sigmoid 分类、特征标准化防泄漏、混淆矩阵核算，再到 k 近邻与海龟汤式的决策树切分。但在二维平面上，一个极简的异或（XOR）对角线分布当场拦住了所有线性模型的去路。
3. 为了解开非线性纠缠并读懂词序上下文，**第三篇**用 ReLU 折线变换折出了隐藏层，用手算前向损失 `50` 与反向梯度 `60` 拆开了自动微分计算图，并用卷积核在空间邻域共享参数，用 RNN、LSTM 与 GRU 在时间步上传递隐藏状态。而当固定长度的状态向量像塞满的行李箱一样装不下长距离线索时，“按需回头查表”的注意力机制（Attention）便应运而生。
4. 进入**第四篇**，我们从 UTF-8 字节与 BPE 子词的区别出发，沿着嵌入查表、多位置注意力、多头拆分和 RoPE 旋转，一步步把序列送进 Transformer 块。因果掩码规定每个位置能看到什么，错开一位的监督目标规定模型应当预测什么；交叉熵的梯度又顺着残差和注意力路径回到参数。等模型真的能续写短句后，温度与 Top-$k$/Top-$p$ 改变的是下一步抽样的分布，KV Cache 节省的则是历史位置的重复计算。生成质量、训练更新与推理加速，由此有了各自可以追查的运算位置。
5. 能续写训练语料，离按要求完成任务还有一段距离。**第五篇**把提示与回答拆开，用 SFT 的损失掩码追查“哪些位置产生损失、哪些表示仍会收到梯度”，再用成对回答解释 DPO 的偏好信号，用概率比、优势与截断解释 PPO 的更新约束。长考与输出口癖也回到训练数据、奖励和生成过程里考察。为了在有限硬件上继续训练和部署，我们又沿着 LoRA 的两条矩阵路径核算参数与梯度，亲手计算量化刻度及还原误差，把模型权重、训练状态和会话缓存分成不同的存储账目。
6. 一旦输入换成照片或声音，“一段输入就是一行文字”的习惯便不够用了。**第六篇**从灰度与 RGB 通道、像素轴排列和图像切块出发，把 ViT 的块序列、CLIP 的图文配对与 VLM 的投影拼接接到已有的矩阵知识上。检测框与分割掩码要求输出空间位置，扩散模型在固定形状上反复预测噪声；语音又要求把采样点、声学帧、频谱与文字位置分清。沿着 ASR—LLM—TTS 的交接记录，以及 RVC 的内容特征、基频和向量检索，我们才能指出一次误识别或音色变化究竟发生在哪一段。
7. 模型能够生成流畅的回答之后，新的现实矛盾再次浮现：模型权重里没有本机私有笔记，嘴上说“已安排计划”也不会真往磁盘写数据。于是**第七篇**跨过 HTTP 进程边界，保存每次实际发送的消息快照；先按权限与版本筛选资料，再比较 BM25、向量相似度及 RRF 排名融合。检索到的片段还要通过来源区间与引用核验，工具提案还要经过严格 JSON 校验与业务检查。模型输出、程序执行、结果回传不断交替，才形成真正能读写外部世界的 Agent 循环。
8. 当工具和协作者不再与主程序待在同一个函数里，**第八篇**开始追查边界两侧各自承担什么。JSON-RPC 报文、MCP 初始化与工具调用、标准输入输出分帧，让“远程工具”落到具体消息上；Skill、Plugin、CLI 与 TUI 则分别组织操作知识、扩展组件和交互入口。Finder、Checker 与 Coordinator 使用隔离的消息窗口接力取证、核验和汇总，协作效果与通信代价都留下记录。再把同一条链路映射到 LangChain 与 LangGraph，框架名称才有了可以逐项对照的职责。
9. 但消息窗口和图里的字段仍会随进程退出而消失。**第九篇**把执行进度写成 SQLite 有限状态机，用 `expected_version` 绑定确认时看到的版本，用事务和幂等键约束重试结果。提交前后强制退出、发件箱重复投递、租约到期后的旧 Worker 回来写入，分别暴露不同的故障窗口；检查点、业务表、回执和防护令牌也就分别承担起恢复位置、保存结果、确认接收与拒绝旧写入的责任。LangGraph 的持久化映射继续沿这些边界核对，节点重入时不会因为框架替我们保存了进度就自动免去副作用。
10. 能恢复执行，还不等于能持续把任务做好。**第十篇**从本书字节分词器下的 192 字节输入预算出发，检查上下文取舍怎样丢掉限制条件，再把原文、摘要、版本与可重建索引分开保存。Attempt 记录一次尝试，业务状态记录已经完成的事实；路径检查、进程隔离、内容验收与授权记录又分别约束执行过程。追踪和 Benchmark 让退步可以被发现，常驻型 Super-agent 则把跨信道输入、独立任务、Router–Worker 调度与 Watchdog 巡检连成长期运行的组织。模型是否还在回答、进程是否还有心跳、任务是否真的取得进展，由此成为三件能够分别检查的事。
11. 当从最底层的浮点数乘法到最外层的分布式状态机全部敞开在桌面上之后，我们在**第十一篇**回到了那个最根本的哲学与社会问题：剥去了技术黑盒的神秘外衣，穿过第一人称“我”的语法影子与中文房间的统计反射，我们看清了逻辑只是人类思维把握客观世界后提炼出的结果，而意识的诞生离不开对自然本能的扬弃（自主需要）与社会性的对象化感性实践；今天一切庞大的 AI 模型与自动化 Harness，本质上都是全人类过往活劳动凝结而成的“死劳动”，是镶嵌在人类生产体系中的工具器官，永远替代不了现实的社会的人去劳动、去承担历史、去在真实的生活中用爱交换爱。

你看，整本书走下来的这条路，本身就是一次完整的认识论实践：**从具体的实际困难出发，在动手解决矛盾的过程中逼出抽象的数学与工程概念；再拿着抽象出来的概念回到下一轮实践里接受检验，撞上新的边界后继续向纵深推进。** 能够背诵一百个流行术语，并不等于理解了系统；只有当你能够把“外部输入 $\rightarrow$ 向量表示 $\rightarrow$ 矩阵前向与梯度反传 $\rightarrow$ 上下文组装与工具校验 $\rightarrow$ 数据库事务落盘 $\rightarrow$ 背后的社会生产与实践关系”这一整条链条在脑子里严丝合缝地重新接通，书本上的知识才真正变成了你自己手里的武器。

## 继续学习的路线

配套代码保留了纸面运算与程序中间状态的对应关系，模型、检索、协议与恢复实验共用 [现代AI示例](https://github.com/KiriAky107/understanding-AI-and-Agents-in-depth/blob/main/%E7%8E%B0%E4%BB%A3AI%E7%A4%BA%E4%BE%8B/README.md)（代码包内：`现代AI示例/README.md`） 中唯一的 `.venv`。继续学习时，可以从已经跑通的一段计算或一次故障实验出发：先改变一个条件，记录输出哪里不同，再去读解释这个差异的论文、教材或源码。以下五条路线都能接回书里的具体问题。

教材的中文版本与电子阅读入口见下文“课程与教材”。自行获取的电子书可放在本地 `拓展阅读/` 目录，仓库根目录的 [README](https://github.com/KiriAky107/understanding-AI-and-Agents-in-depth/blob/main/README.md)（代码包内：`README.md`）保留获取说明。

### 数学与机器学习

如果你想进一步深究正规方程病态矩阵的数值稳定性（SVD 奇异值分解与伪逆）、概率图模型、凸优化理论以及统计学习界限：

* **《动手学深度学习》（Dive into Deep Learning，阿斯顿·张、李沐等著）**：中文社区最优秀的开源交互式深度学习教材（[中文教材](https://zh.d2l.ai/)、[课程安排](https://c.d2l.ai/zh-v2/)、[李沐 B 站课程主页](https://space.bilibili.com/1567748478)），每一节均配有可运行的 PyTorch 代码与练习，极适合作为本书第一至四篇的扩展训练场。

* **Stanford CS229: Machine Learning（吴恩达等主讲，斯坦福大学课程讲义）**：经典机器学习的标杆课程（[https://cs229.stanford.edu/](https://cs229.stanford.edu/)），其公开的数学推导讲义对广义线性模型、指数族分布（理解 Sigmoid 与交叉熵的统计源头）、EM 算法与强化学习马尔可夫决策过程（MDP）给出了极为清晰的证明。

* **Gilbert Strang 的《Introduction to Linear Algebra》与 [MIT 18.06 公开课](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)**：将矩阵乘法彻底还原为“列空间、行空间、零空间与左零空间”四个基本子空间的几何图像，配合本书第一、二篇阅读，能让你对低秩分解（LoRA）与主成分分析（PCA）形成肌肉记忆般的几何直觉。

* **Sheldon Axler，《线性代数应该这样学》第四版（Linear Algebra Done Right，吴俊达、何阳译）**：以向量空间和线性映射为主线，继续讨论内积、谱定理与奇异值分解，最后再引入行列式。读完第一篇的向量图与小矩阵手算后，可以沿这本书补齐定义、证明与习题，把具体例子推进到一般结构。[中文译本与勘误](https://linear.he-yang.top/)、[原作者书页](https://linear.axler.net/)。

* **3Blue1Brown《线性代数的本质》**：用动画把向量、矩阵变换、行列式与特征向量连起来，可边读第一篇边看[B 站官方双语合集](https://www.bilibili.com/video/BV1ys411472E/)。

### 概率论与统计推断

第一篇用具体数字算过贝叶斯公式，第四篇把序列概率拆成条件概率的乘积，第五篇又用期望回报描述策略的收益。继续追查这些运算，需要把条件概率、随机变量、联合分布与条件期望连成体系；回到第二篇的数据学习，还要理解样本为什么能约束未知参数，以及估计结果会怎样随抽样改变。

* **Dimitri P. Bertsekas、John N. Tsitsiklis，《概率导论》第 2 版·修订版（Introduction to Probability，郑忠国、童行伟译）**：适合沿概率模型、随机变量、期望、大数定律一路读到统计推断。可对照[南京大学课程所列的中文版本](https://tcs.nju.edu.cn/wiki/index.php?title=概率论与数理统计_%28Spring_2025%29)，结合 [MIT 6.041SC 官方课程与习题](https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/)完成计算。先回算第一篇的条件概率与方差，再把参数估计、置信区间和假设检验接回第二篇的数据实验。

* **Joseph K. Blitzstein、Jessica Hwang，《概率论导论》（Introduction to Probability，中文翻译版）**：用随机试验、条件化与分布之间的联系建立直觉，继续讨论联合分布、条件期望、极限定理与马尔可夫链。中文译本见[机械工业出版社书页](https://www.cmpedu.com/books/book/5585081.htm)；[Harvard Stat 110 官方课程](https://stat110.hsites.harvard.edu/)另提供免费英文第二版入口。可与上一部教材择一作为主线，另一部用来对照解释，不必同时从头读完两遍。

### 大模型与多模态

如果你想在真实 GPU 集群或消费级显卡上亲手微调 7B 级开源大模型、实践分布式训练、算子加速（FlashAttention）与多模态对齐：

* **上海交通大学《动手学大模型》（Dive into LLMs）开源教程**：针对大模型微调、量化部署、安全对齐、多模态 VLM 与 Agent 开发的中文实战代码库（[https://github.com/Lordog/dive-into-llms](https://github.com/Lordog/dive-into-llms)），可直接衔接本书第四至八篇的模型、部署、多模态与应用实验。

* **Andrej Karpathy 的 [nanoGPT](https://github.com/karpathy/nanoGPT) 与 [llm.c](https://github.com/karpathy/llm.c) 开源项目**：用短短几百行极简、透明的 PyTorch / C 代码从零写出完整 GPT 训练与推理循环的典范之作，其代码洁癖与“拒绝过度封装、直视张量流转”的工程哲学与本书完全一致。

* **HuggingFace 官方开源文档与源码（`transformers` / `peft` / `trl` / `safetensors`）** 以及 **`llama.cpp` 仓库**：从 `trl` 库中 `SFTTrainer`、`DPOTrainer` 调用的损失计算追起，对照本书第五篇的监督掩码、参考策略与偏好差值，检查批处理、长度归一化和数值精度怎样落实到实现。

### 智能体系统工程

如果你想把第七至十篇的智能体架构应用到高并发、长程复杂的生产级业务中：

* **数据库系统与分布式事务经典：Martin Kleppmann《数据密集型应用系统设计》（DDIA）**：虽然这不是一本讲 AI 的书，但它对事务隔离级别、写前日志（WAL）、分布式租约（Lease）、防护令牌（Fencing Token，见本书第九篇（四）节）与异步消息投递的透彻剖析，是写好一切生产级 Agent Runtime 的必修内功。

* **[LangGraph 官方架构文档](https://docs.langchain.com/oss/python/langgraph/graph-api)与 [DeepLearning.AI 短课程](https://www.deeplearning.ai/courses/ai-agents-in-langgraph)**：对照本书第八篇的 `StateGraph` 控制流，以及第九篇的 `SqliteSaver`、`interrupt()` 与业务状态机映射实验，深入掌握复杂图状态归约（Reducers）、子图嵌套与人机协同流。

* **MCP 官方规范与 Anthropic 工程博客**：精读《Building Effective Agents》《Effective Harnesses for Long-Running Agents》等一线工程报告，结合最新开源的常驻型 Super-agent 架构，体会如何用极简的 CLI 工具、外部进度清单与 Router-Worker 隔离跑通长达数小时的研发任务。

### 历史唯物主义与认识论

如果你想顺着第十一篇的思考，进一步夯实剖析技术与社会关系的哲学内功：

* **马克思：《关于费尔巴哈的提纲》（1845）与《德意志意识形态》第一卷第一章（1845—1846）**：历史唯物主义的诞生地，直接阐明了感性实践活动如何作为认识与意识生成的前提，以及物质生活资料生产如何决定社会关系与观念形态。

* **马克思：《1844 年经济学哲学手稿》与《资本论》第一卷（特别是第十三章“机器和大工业”）**：理解对象化劳动与异化劳动的本质区别，看清机器体系作为“死劳动”在资本主义生产关系下如何成为支配“活劳动”的杠杆，以及“以爱交换爱”的真实主体间关系。

* **恩格斯：《家庭、私有制和国家的起源》（1884）与列宁：《唯物主义和经验批判主义》（1908）**：前者从物质生产与人口（劳动力）再生产的分化出发，深刻揭示了私有制、阶级、个体家庭与妇女受压迫的历史根源；后者则在自然科学大变革的背景下，彻底批驳了将数学与逻辑形式脱离物质头脑与实践的唯心主义思潮。

* **毛泽东：《实践论》（1937）与《人的正确思想是从哪里来的？》（1963）**：用最平实晓畅的语言，把“从感性认识到理性认识、再从理性认识到改造世界的实践”的辩证唯物主义认识论讲得通透无比。

## 让学习结果可以复查

在合上这本书、继续你自己的工程研发或理论探索时，有一套贯穿本书始终的工作习惯值得长久保留下来：

**永远为你的认识过程留下可回查、可复现的现场。**
无论是调试一个神经网络的梯度异常、排查一次 RAG 召回的遗漏，还是检验一项长程智能体任务的持久化恢复，一份真正有价值的工程记录，应当老老实实保存下最初的原始问题、导致失败的具体输入、你当时的假设、关键的纸面手算推导、修改了哪几行代码，以及修改前后的实测对比数据。守住一份边界清晰、可随时重建的运行环境（就像本书从头到尾唯一使用的 `.venv` 与 `python -m modern_ai verify`），远比在硬盘里堆满几十个跑不通、分不清版本的项目副本更有力量。正式源码、原始资料与运行日志各归其位，临时测试产生的数据库与缓存用完即焚。

在这个技术名词日新月异、每隔几个月就有新模型号称“颠覆一切”的时代里，保持清醒其实并不难：

* **当训练曲线急速下降时**，别急着欢呼，去打开锁在保险箱里的保留测试集，看看它在未见过的组合上到底学到了什么、漏掉了什么；

* **当智能体在终端里回答“任务已全部圆满完成”时**，别轻信那句流利的自然语言，去查一查 SQLite 的 `runs` 状态表、`plans` 结果表、发件箱回执以及引用的原文区间，看看事实到底有没有落盘；

* **当舆论场上又在渲染“硅基意识觉醒”或贩卖“情绪价值”时**，顺着它的输入上下文、损失函数、调度队列与供电网线一路往回查，看清到底是谁在设定目标、是谁在维护运行条件、又是怎样的社会关系在支配着技术的应用。

具体的、实事求是的考察，会让空洞的概念重新长出血肉，也会让你在面对任何新问题时，脚下始终踩着一块坚实可靠的土地。
